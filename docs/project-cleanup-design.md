# 项目整理设计（2026-10-06）

## 范围与选择

用户已授权调整项目文件位置及调用代码。整理范围为目录、导入、输入输出路径和说明；保留实验算法、参数、随机种子逻辑以及所有原始数据和已有结果。

比较三种方案：仅分类文件改动少但仍重复维护检验代码；完全重写统一实验框架改动较大且会增加实验回归风险；采用公共模块加独立实验包，兼顾清晰和稳定。本次采用第三种。

## 目标目录

- `common/`：共享 bootstrap 检验、Xue 统计量、基投影与项目路径。
- `simulation/`：三个模拟入口和对应生成器，保留原文件名便于对照。
- `empirical/`：HAR 实证入口与加载器。
- `data/har/`：两份原始 HAR CSV；`data/cache/stock/`：历史股票缓存。
- `results/simulation/model1/`：原模拟当前输出，模型 2、3 重跑后写入各自目录。
- `results/empirical/har/experiment_results/` 和 `figures/`：现有 HAR 输出及后续输出。
- `results/history/`：原标记可用的模拟结果及加入 Xue 的历史结果，保留内部文件名与版本标签。
- `archive/stock_empirical/`：原 old 股票代码（Xue 实现与当前不同，独立保留）。
- `archive/results/`：原已标记废弃的结果，保留内部层次与标签。
- `archive/logs/`：调试与历史日志。
- `tests/`：原生成器测试及迁移后导入、路径和计算一致性检查。
- `docs/`：整理设计、迁移及重复文件报告；`.planning/project-cleanup/`：计划、进度、原始代码备份和文件核验清单。

## 调用和数据流

入口用 `python -m simulation.Main_one` 等模块命令启动，入口仍支持直接执行文件。模拟读取对应生成器并调用共享检验；HAR 从项目定位的 data 目录读取，输出到 results。路径根据 `common/paths.py` 所在位置推导，不依赖工作目录。

公共模块合并前去除注释/文档字符串比较实际语句；bootstrap 三份计算相同，仅演示导入不同。Xue 采用中文可读的模拟版本注释与实证版本稳定 p 值计算；共享辅助工具显式保留模拟原先的 `1 - F` 计算，HAR 继续使用 `expm1`，保证原实验行为。旧股票的 xue_test 不并入当前 Xue 模块。

数据、结果不依据文件名直接去重；完全相同的代码只保留一个实际实现，并把原文件保存在 ZIP 中以便恢复。所有原始非环境文件记录 SHA256 与迁移位置，迁移后逐项核验。旧股票代码修正模块和路径引用，但不修正其既有统计、下载或数据回退逻辑。

## 验证

先保存迁移前代码和确定性计算基线。验证新目录导入、异地工作目录的数据读取/结果写入、生成器与两种检验对旧代码的一致性、小规模模拟与 HAR 子抽样以及 Windows 多进程导入。执行原生成器测试和语法检查。完整规模实验耗时较长，整理不自动重跑或覆盖历史结果。

## 复核

目录职责清楚，历史材料与当前入口分离；没有合并名称相似但不同的模型或方法；原始环境不移动。设计与用户授权的整理范围一致。本目录无有效 Git 仓库，因此使用 ZIP、SHA256 清单和迁移文档替代 Git 提交记录。writing-plans 技能未安装，实施阶段使用已有文件规划技能记录步骤。
